# Security policy

Version 0.1.x is the supported line.

agent-cost only reads local files you point it at and prints reports. It makes no network requests and runs no code from log files. Log files can contain private prompts, file paths and secrets, so never paste real session content into an issue; use synthetic lines instead.

Please report vulnerabilities privately through GitHub: open the repository's [Security tab](https://github.com/YusufBeratZengin/agent-cost/security) and choose **Report a vulnerability**. If that button is unavailable, open an issue asking for a private channel, without exploit details. No response-time guarantee is offered.
